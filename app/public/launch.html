Launch a devnet token by email

Email launch@clawdmail.app and Pinch creates an SPL token on Solana devnet (6 decimals, Metaplex metadata, fixed supply), then replies with the mint address, explorer links for each transaction, and the metadata URL.

How to write the email

Subject: Launch My Cool Token (COOL). Optionally put fields in the body:

name: My Cool Token
symbol: COOL
description: A test token for my hackathon demo
wallet: <your devnet Solana address>
  • Name up to 32 characters; symbol 2–10 letters/numbers (uppercased). No links or slurs; those get replaced with defaults.
  • Include your Solana address to receive the whole supply. Without one, the supply goes to a fresh devnet wallet.
  • Mint authority is revoked after minting.

Limits

  • 1 launch per sender per hour, 3 per day, plus a global hourly cap.
  • Mail failing SPF/DKIM, auto-replies and bounces are ignored. Each message gets at most one reply.
  • If the devnet payer wallet runs dry, you'll get a "faucet empty" note instead.
